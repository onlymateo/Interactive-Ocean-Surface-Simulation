# 2026-10-06

I am super excited to start this project tonight. In fact I already worked on the implementation 
of the generation of an infinite ocean using Gerstner and FFT in Roblox.
But I encountered a few technical walls:
- The ocean is not interactive (interactions with boats, characters, beaches...)
- Low performance for a 100x100 grid
- Unrealistic surface materials
- Unrealistic algorithm (visible repetitions)
So I will try to overcome these challenges.

**What I did**
- Initialised the git repository.
- Installed the toolchain on Windows (MSYS2 (UCRT64) with `g++`, `make`).
- Created the window with GLFW and a render loop that clears the screen and swaps buffers.
- Drew a grid of triangles with a perspective camera tilted towards the viewer.
- Made the vertex heights change every frame, so the triangles can move. Edges are drawn on top so each triangle is visible.
- Wrote the README: build steps, config keys, file layout, how to add a wave method or an engine, and a roadmap.
- Wrote today's diary.

**Problems met**
- Limiting my AI usage.
